# Детектор фрод-доменов .RU

## Требования

- Python 3.9+

> **Запуск из России:** crt.sh и certspotter — иностранные сервисы, могут быть недоступны без VPN.
> Меню **[1] Встроенный тест** и меню **[2] Свои домены** работают без интернета / с любым соединением.
> Меню **[3] Сбор из интернета** требует стабильного внешнего соединения не из России!

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python run.py
```

Откроется меню с 4 пунктами.

---

## Что делает каждый пункт меню

### [1] Встроенный тест — быстро, без интернета
Запускает на заранее заготовленных данных. Показывает контраст:
легитимные домены (sberbank.ru, yandex.ru) → **LOW**, фрод-паттерны → **HIGH/CRITICAL**.
Используй, чтобы убедиться что всё работает.

### [2] Проверить свои домены (WHOIS + DNS)
Подаёшь CSV-файл с колонкой `domain`:

```
domain
sber-bonus-2025.ru
vtb-cabinet.ru
sberbank.ru
```

Программа запросит WHOIS и DNS для каждого домена и выдаст оценку.
Нужен интернет. На 10–15 доменов уходит ~10–15 секунд.

### [3] Сбор из интернета
Автоматически ищет свежие .ru домены в Certificate Transparency логах
(crt.sh или certspotter) по 21 бренд-запросу (sber, vtb, tinkoff и др.).
Нужен интернет. Рекомендуется 7–14 дней, 20–50 доменов.

### [4] Посмотреть последний результат
Открывает ранее сохранённый CSV с результатами без повторного анализа.

## Уровни риска

| Уровень | Баллы | Значение |
|---------|-------|----------|
| CRITICAL | 70–100 | Высокая вероятность фрода |
| HIGH | 45–69 | Подозрительный домен |
| MEDIUM | 20–44 | Требует проверки |
| LOW | 0–19 | Скорее всего легитимный |

## Что анализируется

- **Возраст домена** — молодой домен (<30 дней) +35 баллов
- **Схожесть с брендом** — близкое расстояние до sberbank, vtb, tinkoff и др. +30
- **Фрод-ключевые слова** — bonus, cashback, cabinet, verify и др. +20
- **Дешёвый регистратор** — Namecheap, GoDaddy, PDR и др. +8
- **Нет MX-записи** — домен не принимает почту +7
- **Короткий срок регистрации** — <400 дней +10

## Структура файлов

```
run.py               — запуск (меню)
main.py              — CLI-интерфейс (python main.py --help)
fraud_detector.py    — движок оценки рисков
data_collector.py    — сбор WHOIS, DNS, CT-логов
requirements.txt     — зависимости
whois_fraud_test.csv — тестовый набор (14 доменов для проверки WHOIS)
my_domains.csv       — шаблон для своих доменов (только колонка domain)
```
